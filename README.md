# منيو مطعم زنجر كينج (Zinger King) 👑🍔

الموقع الرسمي لقائمة طعام مطعم **زنجر كينج** التفاعلية بالجنيه المصري، مع إمكانية الطلب المباشر عبر واتساب وتحديد نوع الطلب (دليفري / استلام من المطعم) وطريقة الدفع (كاش / فودافون كاش / انستا باي).

---

## 📂 محتويات وملفات المشروع

```text
restaurant-menu/
├── index.html        # الصفحة الرئيسية (تدعم المسارات المباشرة وتنسيقات الحماية الذاتية)
├── style.css         # ملف التنسيقات الرئيسي (تصميم داكن فخم مع دعم الهواتف والشاشات)
├── app.js            # ملف التحكم التفاعلي (السلة، البحث، ساعات العمل، رسائل واتساب)
├── .nojekyll         # ملف أساسي يضمن لـ GitHub Pages تشغيل وقراءة جميع الملفات دون استثناء
├── css/
│   └── style.css     # نسخة إضافية للتوافق مع بنية المجلدات الفرعية
├── js/
│   └── app.js        # نسخة إضافية للتوافق مع بنية المجلدات الفرعية
└── README.md         # دليل التثبيت والرفع على GitHub
```

## 🚀 خطوات الرفع على GitHub وتشغيل GitHub Pages في دقيقة واحدة

### الخطوة 1: رفع الملفات إلى مستودعك على GitHub
1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (**New Repository**) أو ادخل إلى مستودعك الحالي.
2. اضغط على زر **Add file** ثم اختر **Upload files**.
3. اسحب وأفلت جميع الملفات والمجلدات الموجودة في هذا المجلد:
   - `index.html`
   - `style.css`
   - `app.js`
   - مجلد `css` ومجلد `js`
   - ملف `.nojekyll`
4. اضغط على الزر الأخضر في الأسفل: **Commit changes**.

---

### الخطوة 2: تفعيل الاستضافة المجانية (GitHub Pages)
1. من شريط التبويبات العلوي في مستودعك، اضغط على **Settings** (الإعدادات ⚙️).
2. من القائمة الجانبية على اليسار، اضغط على **Pages**.
3. في قسم **Build and deployment**:
   - تأكد أن **Source** مضبوط على: `Deploy from a branch`.
   - في خانة **Branch**: اختر `main` (أو `master`)، واترك المجلد بجانبه `/ (root)`.
   - اضغط على زر **Save**.

---

### الخطوة 3: استلام رابط الموقع المباشر 🌐
- انتظر حوالي 30 إلى 60 ثانية، ثم حدّث صفحة **Pages**؛ سيظهر لك مستطيل ملون يحتوي على رابط موقعك المباشر:
  `https://<your-username>.github.io/<repository-name>/`
- عند فتح الرابط، سيعمل الموقع بكامل تنسيقاته وألوانه وحركاته الفخمة دون أي أخطاء!

---

## 🛠️ تفاصيل الإصلاح الفني الذي تم تنفيذه
- **سبب المشكلة السابقة:** كانت هناك مسارات تبدأ بعلامة السلاش المطلقة `/zinger.king/` مما جعل المتصفح على GitHub Pages يبحث في جذر النطاق `username.github.io/zinger.king/...` بدلاً من مجلد المستودع، مما أدى لفشل تحميل ملف `style.css` و `app.js` وبالتالي ظهور الصفحة بدون تنسيق وتمدد أيقونة التاج لكامل الشاشة.
- **الحل الجذري:** 
  1. تحويل كافة المسارات إلى مسارات نسبية ذكية (`./style.css` و `./app.js`).
  2. توفير ملفات التنسيق والجافاسكريبت في كل من المجلد الرئيسي للجذر وفي المجلدات الفرعية (`css/` و `js/`) حتى يعمل الموقع في كلتا الحالتين سواء تم رفع الملفات مفردة أو داخل مجلدات.
  3. إضافة تنسيقات حماية مدمجة (Critical CSS) داخل هيدر الصفحة تضمن تحديد أبعاد الشعار ومنع تمدد SVG وإخفاء النوافذ المنبثقة تلقائياً حتى قبل اكتمال تحميل أي ملف خارجي.
  4. إضافة ملف `.nojekyll` لمنع محرك Jekyll من تجاهل أو تعطيل أي ملفات ومسارات على خوادم GitHub.
